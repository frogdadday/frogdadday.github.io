## Included and excluded material

Included: Dart application source, native Android Kotlin implementation, Android manifests and XML resources, tests, privacy policy source, Gradle configuration, `pubspec.yaml`, and `pubspec.lock`.

Excluded: APK/AAB release binaries, signing keys and credentials, private SDK/toolchain caches, local machine setup scripts, internal project review/status documents, and original artwork / raster launcher image files. This includes `assets/cosmic_chores_launcher_master.png`, which is still referenced by `pubspec.yaml`, plus the Android mipmap PNGs referenced by the launcher XML. Consequently, this published snapshot is **not build-complete as-is**: those artwork assets must be separately restored by someone authorized to use them, and the asset references must be satisfied before building. Frogdadday branding and artwork remain excluded from the license grant.
