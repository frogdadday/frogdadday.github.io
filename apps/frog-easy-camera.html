How to install a direct APK

  1. Once a public release is available, download the APK from this page on your Android phone.
  2. Open the downloaded file. Android may ask you to allow installations from your browser or file manager.
  3. Review any system warnings and install only if you trust the source. Afterward, turn off the extra install permission if you enabled it.

Website installations do not receive automatic Google Play updates. Future versions can be downloaded here and installed over the old one when signed with the same key.
