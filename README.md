# Frogdadday website

This is a static, GitHub Pages-ready website. It uses local copies of the real launcher icons from the nine public-facing app projects and contains no download links while the apps are in testing or coming soon.

## Preview on this computer

Open `index.html` directly for a quick preview, or run a local web server from this folder:

```powershell
python -m http.server 4173
```

Then visit `http://localhost:4173`.

## GitHub Pages

The folder can be committed at the root of a Pages repository. No build step is required. Publishing has intentionally not been performed.
